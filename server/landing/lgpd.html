LGPD — Como protegemos seus dados

Lei 13.709/2018  ·  Última atualização: 26 de maio de 2026

O Barber Pro está comprometido com a Lei Geral de Proteção de Dados (LGPD). Esta página explica de forma clara como aplicamos a lei no nosso dia a dia.

O que é a LGPD?

A Lei Geral de Proteção de Dados (Lei 13.709/2018) é a legislação brasileira que regula o tratamento de dados pessoais. Ela entrou em vigor em setembro de 2020 e é fiscalizada pela Autoridade Nacional de Proteção de Dados (ANPD).

Bases legais que utilizamos

Todo tratamento de dados no Barber Pro é baseado em uma das seguintes bases legais previstas na LGPD:

  • Execução de contrato — para operar a plataforma e prestar o serviço contratado
  • Consentimento — para envio de comunicações de marketing (quando aplicável)
  • Legítimo interesse — para melhorias da plataforma e segurança
  • Obrigação legal — para cumprimento de exigências fiscais e regulatórias

Encarregado de Dados (DPO)

Nosso Encarregado de Proteção de Dados está disponível para:

  • Receber comunicações dos titulares de dados
  • Orientar sobre o tratamento de dados pessoais
  • Atuar como canal de comunicação com a ANPD

Contato: suporte@usebarberpro.com

Como as barbearias devem usar o sistema

As barbearias que usam o Barber Pro são controladoras de dados dos seus próprios clientes. Isso significa que têm responsabilidades perante a LGPD, incluindo:

  • Informar os clientes sobre o uso dos seus dados (nome, telefone, histórico)
  • Coletar apenas os dados necessários para a prestação do serviço
  • Atender solicitações de exclusão de dados de clientes
  • Não compartilhar dados de clientes com terceiros sem base legal

O Barber Pro oferece ferramentas para que as barbearias cumpram essas obrigações, como o registro de consentimento (LGPD) na criação de novos clientes.

Incidente de segurança

Em caso de incidente de segurança que possa afetar dados pessoais, o Barber Pro se compromete a:

  • Investigar e conter o incidente imediatamente
  • Notificar os usuários afetados em até 72 horas
  • Comunicar a ANPD quando exigido pela regulamentação
  • Tomar medidas para evitar a recorrência

Relatório de Impacto (RIPD)

Para operações de alto risco, mantemos Relatórios de Impacto à Proteção de Dados Pessoais (RIPD) conforme exigido pela LGPD. Esses relatórios estão disponíveis para consulta pela ANPD mediante solicitação.

Exercer seus direitos

Para exercer qualquer direito previsto na LGPD, entre em contato pelo e-mail suporte@usebarberpro.com com o assunto "Direitos LGPD". Responderemos em até 15 dias úteis.

Se não ficar satisfeito com nossa resposta, você pode contatar a ANPD pelo site gov.br/anpd.
